  <action>
    Create `template/Editor/GameKit/Utils/PropertySerializer.cs`:
    - Static class in `GameKit.Utils` namespace
    - Public static `ReadValue(SerializedProperty prop)` returning `object` (JSON-safe)
    - Switch on `prop.propertyType` covering all common types:
      - `Integer`: return `prop.intValue`
      - `Boolean`: return `prop.boolValue`
      - `Float`: return `prop.floatValue`
      - `String`: return `prop.stringValue`
      - `Enum`: wrap in try-catch; try `prop.enumNames[prop.enumValueIndex]`, catch IndexOutOfRangeException and fall back to `prop.intValue` (handles stale enum data per research pitfall 4)
      - `Color`: return `new { r = c.r, g = c.g, b = c.b, a = c.a }`
      - `Vector2`: return `new { x, y }`
      - `Vector3`: return `new { x, y, z }`
      - `Vector4` / `Quaternion`: return `new { x, y, z, w }`
      - `Rect`: return `new { x, y, width, height }`
      - `Bounds`: return `new { center = new { x, y, z }, size = new { x, y, z } }`
      - `Vector2Int`: return `new { x, y }`
      - `Vector3Int`: return `new { x, y, z }`
      - `RectInt`: return `new { x, y, width, height }`
      - `BoundsInt`: return `new { position = new { x, y, z }, size = new { x, y, z } }`
      - `ObjectReference`: if `prop.objectReferenceValue != null`, return `new { name, type = obj.GetType().Name, instanceId = obj.GetInstanceID() }`; else return null
      - `LayerMask`: return `prop.intValue`
      - `ArraySize`: return `prop.intValue`
      - `Character`: return `prop.intValue` (char code)
      - `AnimationCurve`: return `new { keys = prop.animationCurveValue.length }` (summary, not full curve data)
      - `Gradient`: return `"<gradient>"` (not trivially serializable)
      - `ExposedReference`: return `"<exposed reference>"`
      - `ManagedReference`: return `new { type = prop.managedReferenceFullTypename }` if non-empty, else null
      - `Hash128`: return `prop.hash128Value.ToString()`
      - `Generic` (struct/class): return `"<complex>"` -- do NOT recursively expand; the top-level iteration with NextVisible already flattens nested properties via propertyPath
      - `default`: return null
    - Public static `SerializeProperties(Component component, int maxDepth)` returning `List<object>`:
      - Create `new SerializedObject(component)`, call `.Update()`
      - Get iterator via `.GetIterator()`
      - Use `NextVisible(enterChildren)` pattern: first call with `enterChildren = true`, then `false` for subsequent
      - For each property, add `new { name = prop.name, displayName = prop.displayName, type = prop.propertyType.ToString(), value = ReadValue(prop), path = prop.propertyPath }` to list
      - Respect maxDepth by checking `prop.depth` against maxDepth (if maxDepth > 0 and prop.depth > maxDepth, skip)
      - Return the property list

    Create `template/Editor/GameKit/Handlers/InspectHandler.cs`:
    - Static class in `GameKit.Handlers` namespace
    - `Handle(HttpListenerRequest request)` returning `ApiResponse`:
      - Read query params: `path` (required -- the GameObject hierarchy path), `component` (optional -- filter to specific component type)
      - If `path` is missing, return `ApiResponse.Error("MISSING_PATH", "Query parameter 'path' is required")`
      - Call `SceneService.FindGameObjectByPath(path)` (from plan 04-01)
      - If null, return `ApiResponse.Error("NOT_FOUND", "GameObject not found: {path}")`
      - Get all components via `go.GetComponents<Component>()`
      - For each component:
        - If component is null (missing script): add `new { type = "Missing (MonoScript)", properties = (object)null }`
        - If `component` filter is set and `component.GetType().Name` does not match (case-insensitive), skip
        - Otherwise: call `PropertySerializer.SerializeProperties(component)`, determine enabled state via helper (check if IsBehaviourEnabled: cast to Behaviour, check .enabled; Renderer check .enabled; Collider check .enabled; default true), add `new { type = typeName, enabled, properties }`
      - Wrap full result: `new { name = go.name, path, tag = go.tag, layer = LayerMask.LayerToName(go.layer), activeSelf = go.activeSelf, activeInHierarchy = go.activeInHierarchy, isStatic = go.isStatic, components = resultList }`
      - Return `ApiResponse.Success(result)`
    - Private helper `IsComponentEnabled(Component c)`: try casting to `Behaviour` (has .enabled), then `Renderer`, then `Collider`; return true if none match (Transform, etc. are always "enabled")

    Update `template/Editor/GameKit/RequestRouter.cs`:
    - Add route: `GET /api/inspect` -> `InspectHandler.Handle()` in the try block
    - Standard ApiResponse flow (no bypass needed)
