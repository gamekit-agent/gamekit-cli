  <action>
    Create `template/Editor/GameKit/Services/SceneService.cs`:
    - Static class in `GameKit.Services` namespace (no [InitializeOnLoadMethod] needed -- no persistent state)
    - `ListScenes()` method: uses `AssetDatabase.FindAssets("t:Scene")` + `GUIDToAssetPath()` to find all .unity files; cross-references with `EditorBuildSettings.scenes` to include `inBuildSettings` and `enabled` flags; returns list of anonymous objects with `path`, `name`, `inBuildSettings`, `enabled`
    - `OpenScene(string sceneNameOrPath)` method: if input ends with `.unity`, open directly via path; otherwise search by name using `AssetDatabase.FindAssets("t:Scene " + name)`, filter exact name matches with `Path.GetFileNameWithoutExtension()`, error if 0 matches ("Scene not found"), error if >1 matches (list all paths), auto-save dirty scene with `EditorSceneManager.SaveOpenScenes()` before opening; use `EditorSceneManager.OpenScene()` to open; return `{ path, name, rootCount }`
    - `GetHierarchy(string nameFilter, string componentFilter, int maxDepth)` method: get active scene via `SceneManager.GetActiveScene()`, get root GameObjects via `scene.GetRootGameObjects()`, build tree recursively with `BuildNode()` helper; return `{ scene, scenePath, rootCount, hierarchy }`
    - `BuildNode(Transform t, string nameFilter, string componentFilter, int depth, int maxDepth)` private helper: recursively traverse children via `Transform.GetChild(i)`; each node has `name`, `path` (built by walking parent chain), `activeSelf`, `activeInHierarchy`, `components` (list of component type names from `GetComponents<Component>()`, skip null components for missing scripts), `children`; when filters provided: include node if name matches (case-insensitive Contains) OR component matches OR has matching descendants; if maxDepth > 0 and depth >= maxDepth, stop recursion
    - `FindGameObjectByPath(string path)` public helper: splits path by '/', walks from root GameObjects through `Transform.Find()` for each segment to find inactive objects; returns null if not found (do NOT use `GameObject.Find()` which skips inactive objects)
    - Helper `GetHierarchyPath(Transform t)`: walk parent chain to build slash-delimited path

    Create `template/Editor/GameKit/Handlers/SceneHandler.cs`:
    - Static class in `GameKit.Handlers` namespace
    - `HandleList(HttpListenerRequest request)`: calls `SceneService.ListScenes()`, wraps in `ApiResponse.Success()`
    - `HandleOpen(HttpListenerRequest request)`: reads JSON body `{ "scene": "name-or-path" }` using StreamReader + Newtonsoft `JObject.Parse()`, calls `SceneService.OpenScene(scene)`, wraps in `ApiResponse.Success()`; catches Exception for not-found/ambiguous errors, returns `ApiResponse.Error("SCENE_NOT_FOUND", message)` or `ApiResponse.Error("SCENE_AMBIGUOUS", message)`

    Create `template/Editor/GameKit/Handlers/HierarchyHandler.cs`:
    - Static class in `GameKit.Handlers` namespace
    - `Handle(HttpListenerRequest request)`: reads query params `name`, `component`, `depth` (parse int, default 0 = unlimited) from `request.QueryString`; calls `SceneService.GetHierarchy(name, component, depth)`, wraps in `ApiResponse.Success()`

    Update `template/Editor/GameKit/RequestRouter.cs`:
    - Add route: `GET /api/scene/list` -> `SceneHandler.HandleList()`
    - Add route: `POST /api/scene/open` -> `SceneHandler.HandleOpen()`
    - Add route: `GET /api/hierarchy` -> `HierarchyHandler.Handle()`
    - Add routes in the try block alongside existing routes, following the same if/else pattern
    - All new routes use standard ApiResponse flow (no bypass needed)
  </action>

    - `scene list` subcommand: GET request to `/scene/list`, `outputSuccess(result, opts)`, then stderr log each scene formatted as `"  {name} ({path}){inBuildSettings ? ' [build]' : ''}{enabled ? '' : ' (disabled)'}"`, with a count line `logSuccess("Found N scene(s)")`
