  <action>
    **AuthoringService.cs** -- Static class in `GameKit.Services` namespace. All methods check `EditorApplication.isPlaying` first and throw `"Cannot modify scene during play mode. Stop play mode first."` if true. Methods:

    - `CreateGameObject(string name, string parentPath)`: Use `ObjectFactory.CreateGameObject(name)` for auto-undo. If parentPath is not null/empty, call `SceneService.FindGameObjectByPath(parentPath)` to resolve parent, throw if not found, then call `Undo.SetTransformParent(go.transform, parent.transform, false, "Set Parent")`. Return anonymous object `{ name, path (from GetHierarchyPath), instanceId }`.

    - `DestroyGameObject(string path)`: Resolve via `SceneService.FindGameObjectByPath(path)`, throw if not found. Capture name before destruction. Call `Undo.DestroyObjectImmediate(go)`. Return `{ destroyed = name, path }`.

    - `SetTransform(string path, Vector3? position, Vector3? rotation, Vector3? scale)`: Resolve via FindGameObjectByPath, throw if not found. Call `Undo.RecordObject(go.transform, "Set Transform")`. If position.HasValue, set `go.transform.localPosition`. If rotation.HasValue, set `go.transform.localEulerAngles`. If scale.HasValue, set `go.transform.localScale`. Return `{ name, path, position (xyz object), rotation (xyz object), scale (xyz object) }` with current values.

    Helper: `GetHierarchyPath(Transform t)` -- walk up parent chain building "Parent/Child/Grandchild" path. This exists in SceneService already as private. Either make it internal/public or duplicate in AuthoringService. Preference: make SceneService.GetHierarchyPath internal or add a public version to SceneService. If that is too invasive, duplicate the 8-line helper.

    **TypeResolver.cs** -- Static class in `GameKit.Utils` namespace. Lazy-initialized `Dictionary<string, Type>` (case-insensitive via `StringComparer.OrdinalIgnoreCase`). On first call, populate from `TypeCache.GetTypesDerivedFrom<Component>()`, skipping abstract types. Store by `type.Name` (short name), first-wins for duplicates.

    Method `ResolveComponentType(string typeName)`:
    1. Try dictionary lookup by short name
    2. Fallback: `Type.GetType(typeName)` for fully qualified names, validate `typeof(Component).IsAssignableFrom()`
    3. Return null if not found

    This utility is needed by Plan 02 (AddComponent) but is created here because it has no dependencies and Plan 02 depends on it.

    **CreateHandler.cs** -- Static class in `GameKit.Handlers` namespace. `Handle(HttpListenerRequest request)` method. Parse POST JSON body (same pattern as SceneHandler.HandleOpen): read InputStream, JObject.Parse, extract `name` (required, error if missing) and `parent` (optional). Call `AuthoringService.CreateGameObject(name, parent)`. Wrap exceptions: "not found" -> `PARENT_NOT_FOUND` error code, "play mode" -> `PLAY_MODE` error code.

    **DestroyHandler.cs** -- Same pattern. Extract `path` from POST JSON body (required). Call `AuthoringService.DestroyGameObject(path)`. Error codes: `MISSING_PATH`, `NOT_FOUND`, `PLAY_MODE`.

    **TransformHandler.cs** -- Same pattern. Extract `path` (required), `position` (optional {x,y,z}), `rotation` (optional {x,y,z}), `scale` (optional {x,y,z}) from POST JSON body. Convert JToken objects to `Vector3?` using `new Vector3(token["x"].Value<float>(), ...)`. Call `AuthoringService.SetTransform(path, pos, rot, scl)`. Error codes: `MISSING_PATH`, `NOT_FOUND`, `PLAY_MODE`.

    **RequestRouter.cs** -- Add six new route entries in the if/else chain (before the 404 fallback):
    ```
    POST /api/create    -> CreateHandler.Handle
    POST /api/destroy   -> DestroyHandler.Handle
    POST /api/transform -> TransformHandler.Handle
    ```
    (The other three routes for add-component, set, will be added in Plan 02.)

    **create.ts** -- Follow the exact pattern of `src/commands/scene.ts` (registerSceneCommand). Export `registerCreateCommand(program: Command)`.

    Define `CreateResult` interface: `{ name: string; path: string; instanceId: number }`.

    Register: `program.command('create <name>')` with `.description('Create a new GameObject in the scene')` and `.option('--parent <path>', 'Parent GameObject path')`.

    Action: get globalOpts, getConnection, `request<CreateResult>(info.port, 'POST', '/create', { name, parent: opts.parent })`. outputSuccess(result, globalOpts). logSuccess(`Created: ${result.path}`).

    Error handling: catch GameKitError, match `PARENT_NOT_FOUND` and `PLAY_MODE` for helpful messages, then outputError.

    **destroy.ts** -- Export `registerDestroyCommand(program: Command)`.

    Define `DestroyResult` interface: `{ destroyed: string; path: string }`.

    Register: `program.command('destroy <path>')` with `.description('Remove a GameObject from the scene')`.

    Action: request<DestroyResult>(info.port, 'POST', '/destroy', { path }). logSuccess(`Destroyed: ${result.destroyed}`).

    Error handling: `NOT_FOUND` and `PLAY_MODE` codes.

    **transform.ts** -- Export `registerTransformCommand(program: Command)`.

    Define `TransformResult` interface with name, path, position/rotation/scale as `{x:number,y:number,z:number}`.

    Register: `program.command('transform <path>')` with three options:
    - `--position <xyz>` "Set local position (x,y,z)"
    - `--rotation <xyz>` "Set local rotation in euler angles (x,y,z)"
    - `--scale <xyz>` "Set local scale (x,y,z)"

    Action: Parse comma-separated values. Helper function `parseVector3(str: string): {x:number,y:number,z:number}` splits on comma, parses 3 floats, throws if invalid. Build body: `{ path, position: opts.position ? parseVector3(opts.position) : undefined, ... }` (same for rotation, scale). Request POST /transform.

    Human-readable output: log position, rotation, scale values.

    Error handling: `NOT_FOUND`, `PLAY_MODE`, also handle parseVector3 errors with a helpful message.
