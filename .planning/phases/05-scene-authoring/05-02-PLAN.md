  <action>
    **PropertyDeserializer.cs** -- Static class in `GameKit.Utils` namespace. Single method `WriteValue(SerializedProperty prop, JToken value)`. Type switch on `prop.propertyType` mirroring PropertySerializer.ReadValue:

    - `Integer`: `prop.intValue = value.Value<int>()`
    - `Boolean`: `prop.boolValue = value.Value<bool>()`
    - `Float`: `prop.floatValue = value.Value<float>()`
    - `String`: `prop.stringValue = value.Value<string>()`
    - `Enum`: If `value.Type == JTokenType.String`, look up index in `prop.enumNames` via `Array.IndexOf`, throw if not found listing valid values. If `value.Type == JTokenType.Integer`, set `prop.enumValueIndex = value.Value<int>()`.
    - `Color`: `value.ToObject<>` or parse JObject with r,g,b,a float fields. `prop.colorValue = new Color(r, g, b, a)`.
    - `Vector2`: Parse x,y from JObject. `prop.vector2Value = new Vector2(x, y)`.
    - `Vector3`: Parse x,y,z from JObject. `prop.vector3Value = new Vector3(x, y, z)`.
    - `Vector4`: Parse x,y,z,w from JObject. `prop.vector4Value = new Vector4(x, y, z, w)`.
    - `Quaternion`: Parse x,y,z,w from JObject. `prop.quaternionValue = new Quaternion(x, y, z, w)`.
    - `Rect`: Parse x,y,width,height. `prop.rectValue = new Rect(x, y, w, h)`.
    - `Bounds`: Parse center and size sub-objects. `prop.boundsValue = new Bounds(center, size)`.
    - `Vector2Int`: Parse x,y as int. `prop.vector2IntValue = new Vector2Int(x, y)`.
    - `Vector3Int`: Parse x,y,z as int. `prop.vector3IntValue = new Vector3Int(x, y, z)`.
    - `RectInt`: Parse x,y,width,height as int. `prop.rectIntValue = new RectInt(x, y, w, h)`.
    - `BoundsInt`: Parse position and size sub-objects. `prop.boundsIntValue = new BoundsInt(pos, size)`.
    - `ObjectReference`: If JTokenType.Integer, `EditorUtility.InstanceIDToObject(id)` -> `prop.objectReferenceValue`. If JTokenType.String, `AssetDatabase.LoadAssetAtPath<UnityEngine.Object>(path)` -> `prop.objectReferenceValue`. If JTokenType.Null, `prop.objectReferenceValue = null`.
    - `LayerMask`: `prop.intValue = value.Value<int>()`.
    - default: throw `$"Unsupported property type: {prop.propertyType}"`.

    Use JToken access pattern: `value["x"]?.Value<float>() ?? 0f` for safety.

    **AddComponentHandler.cs** -- Static class in `GameKit.Handlers`. `Handle(HttpListenerRequest request)` method. Parse POST body for `path` (required) and `type` (required). Check `EditorApplication.isPlaying` -> PLAY_MODE error. Resolve GameObject via `SceneService.FindGameObjectByPath(path)` -> NOT_FOUND error. Resolve type via `TypeResolver.ResolveComponentType(type)` -> TYPE_NOT_FOUND error (include the type name in the message). Call `ObjectFactory.AddComponent(go, resolvedType)` (auto-undo). Return `{ gameObject = go.name, component = resolvedType.Name, path }`.

    **SetPropertyHandler.cs** -- Static class in `GameKit.Handlers`. `Handle(HttpListenerRequest request)` method. Parse POST body for `path` (required), `component` (required -- component type name), `property` (required -- SerializedProperty path), `value` (required -- JToken). Check play mode. Resolve GameObject. Find component on GO by matching type name (case-insensitive `GetComponents<Component>()` loop, match `comp.GetType().Name`). Create `new SerializedObject(component)`, call `so.Update()`. Find property via `so.FindProperty(propertyPath)` -> PROPERTY_NOT_FOUND error. Call `PropertyDeserializer.WriteValue(prop, value)`. Call `so.ApplyModifiedProperties()` (auto-records undo). Read back via `so.Update()` + `so.FindProperty(propertyPath)` + `PropertySerializer.ReadValue(readProp)`. Return `{ gameObject, component, property, value = readBackValue }`.

    Error codes: `MISSING_FIELD`, `NOT_FOUND`, `TYPE_NOT_FOUND`, `COMPONENT_NOT_FOUND`, `PROPERTY_NOT_FOUND`, `PLAY_MODE`, `INVALID_VALUE`.


  <action>
    **add-component.ts** -- Export `registerAddComponentCommand(program: Command)`.

    Define `AddComponentResult` interface: `{ gameObject: string; component: string; path: string }`.

    Register: `program.command('add-component <path> <type>')` with `.description('Add a component to a GameObject')`.

    Action: getConnection, `request<AddComponentResult>(info.port, 'POST', '/add-component', { path, type })`. logSuccess(`Added ${result.component} to ${result.gameObject}`).

    Error handling: `NOT_FOUND`, `TYPE_NOT_FOUND`, `PLAY_MODE`. For TYPE_NOT_FOUND, suggest: "Use the full type name if ambiguous (e.g., UnityEngine.Camera)".

    **set.ts** -- Export `registerSetCommand(program: Command)`.

    Define `SetResult` interface: `{ gameObject: string; component: string; property: string; value: unknown }`.

    Register: `program.command('set <path> <component> <property> <value>')` with `.description('Set a property value on a component')`.

    Action: Parse the `<value>` argument intelligently before sending to Unity:
    - If value looks like a comma-separated triplet (matches `/^-?\d+\.?\d*,-?\d+\.?\d*,-?\d+\.?\d*$/`), parse as Vector3 `{x, y, z}` (split on comma, parseFloat each)
    - If value looks like a comma-separated quad (4 numbers), parse as Vector4/Color `{x, y, z, w}` or `{r, g, b, a}` -- send as `{x, y, z, w}` (the handler/deserializer will use whatever property type expects)
    - If value is "true" or "false", send as boolean
    - If value is parseable as a number, send as number
    - Otherwise, send as string (handles enum names like "Dynamic", "Interpolate")
    - If value starts with "{" try JSON.parse for complex objects

    This smart parsing means the CLI accepts: `gamekit set Player Rigidbody mass 5` (number), `gamekit set Player Rigidbody useGravity true` (bool), `gamekit set Light Light m_Color 1,0,0,1` (color), `gamekit set Player Transform m_LocalPosition 1,2,3` (vector3).

    Request: `request<SetResult>(info.port, 'POST', '/set', { path, component, property, value: parsedValue })`.

    logSuccess with property name and new value.

    Error handling: `NOT_FOUND`, `COMPONENT_NOT_FOUND`, `PROPERTY_NOT_FOUND`, `PLAY_MODE`, `INVALID_VALUE`. Helpful tips: for PROPERTY_NOT_FOUND suggest using `gamekit inspect <path> --component <type>` to see available properties.
