**ScreenshotService.cs** — Create `template/Editor/GameKit/Services/ScreenshotService.cs`:
- Namespace: `GameKit.Services`
- Static class `ScreenshotService`
- Core method: `public static byte[] CaptureCamera(Camera camera, int width, int height)`:
  - Create `new RenderTexture(width, height, 24, RenderTextureFormat.Default)`
  - Save `camera.targetTexture` and `RenderTexture.active`
  - Set camera target to RT, set RT as active
  - Call `camera.Render()`
  - Create `new Texture2D(width, height, TextureFormat.RGB24, false)`
  - `tex.ReadPixels(new Rect(0, 0, width, height), 0, 0)` then `tex.Apply()`
  - `byte[] pngBytes = tex.EncodeToPNG()`
  - Cleanup in `finally` block: restore camera.targetTexture, RenderTexture.active, `Object.DestroyImmediate(tex)`, `Object.DestroyImmediate(rt)`
  - Return pngBytes
- `public static Camera FindGameCamera()`: Try `Camera.main`, fallback to `Camera.allCameras[0]`, return null if none
- `public static Camera FindSceneViewCamera()`: Return `SceneView.lastActiveSceneView?.camera` (needs `using UnityEditor;`)
- `public static Camera FindNamedCamera(string name)`: `GameObject.Find(name)?.GetComponent<Camera>()`, return null if not found
- Uses: `using UnityEngine; using UnityEditor;`

**ScreenshotHandler.cs** — Create `template/Editor/GameKit/Handlers/ScreenshotHandler.cs`:
- Namespace: `GameKit.Handlers`
- Static class `ScreenshotHandler`
- This handler manages its own response lifecycle (like ConsoleHandler.HandleStream for SSE) because it may return binary PNG data instead of JSON.
- `public static void Handle(HttpListenerContext context)`:
  - Parse query parameters: `source` (default "game"), `format` (default "file"), `width` (default 1920), `height` (default 1080)
  - Find camera based on source: "scene" -> `FindSceneViewCamera()`, "game" -> `FindGameCamera()`, anything else -> `FindNamedCamera(source)`
  - If camera is null, write JSON error response (400) with `ApiResponse.Error("CAMERA_NOT_FOUND", descriptive message)` — specific messages: "No active Scene view" for scene, "No cameras in scene" for game, "Camera '{name}' not found" for named
  - Call `ScreenshotService.CaptureCamera(cam, width, height)` to get `byte[] pngBytes`
  - If format == "binary": set `ContentType = "image/png"`, set `ContentLength64`, write pngBytes to OutputStream
  - If format == "file": create directory `.gamekit/screenshots/` relative to `Directory.GetCurrentDirectory()`, generate filename `screenshot_{DateTime.Now:yyyyMMdd_HHmmss}.png`, write bytes with `File.WriteAllBytes`, return JSON via `ApiResponse.Success(new { path = filePath })` serialized with `JsonConvert.SerializeObject`
  - Catch exceptions: write JSON error with `ApiResponse.Error("SCREENSHOT_FAILED", ex.Message)` at 500
  - Always close response in finally block
- Helper methods: `WriteJsonResponse(context, ApiResponse, statusCode)`, `WriteBinaryResponse(context, byte[])`, `ParseInt(string val, int defaultVal)` — keep these private static within the handler
- Uses: `using System; using System.IO; using System.Net; using System.Text; using GameKit.Models; using GameKit.Services; using Newtonsoft.Json;`

**screenshot.ts** — Create `src/commands/screenshot.ts` following the `registerPlayCommand` pattern from `src/commands/play.ts`:
- `export function registerScreenshotCommand(program: Command): void`
- Register `program.command('screenshot')` with description "Capture a screenshot from Unity"
- Options:
  - `--scene` — "Capture the Scene view instead of Game view"
  - `--camera <name>` — "Capture from a specific camera"
  - `--width <pixels>` — "Screenshot width" (default "1920")
  - `--height <pixels>` — "Screenshot height" (default "1080")
  - `--output <path>` — "Save screenshot to specific file path"
  - `--stdout` — "Write raw PNG binary to stdout"
- Action handler (async):
  - `const globalOpts = program.opts() as OutputOptions`
  - `const info = await getConnection(process.cwd())`
  - Determine source: `opts.scene ? 'scene' : (opts.camera ?? 'game')`
  - Build query string: `?source=${encodeURIComponent(source)}&width=${opts.width}&height=${opts.height}`
  - **If `--stdout` flag is set (binary mode):**
    - Append `&format=binary` to query string
    - Use raw `fetch` to `http://localhost:${info.port}/api/screenshot${params}` with `signal: AbortSignal.timeout(30000)`
    - Check `res.ok` — if not, parse error body and throw GameKitError
    - `const buffer = Buffer.from(await res.arrayBuffer())`
    - `process.stdout.write(buffer)`
    - Return (no outputSuccess, no log — binary mode is silent on stderr)
  - **Else (file mode, default):**
    - Append `&format=file` to query string
    - Use `request<{ path: string }>(info.port, 'GET', '/screenshot' + params, undefined, 30000)` — 30s timeout because camera rendering can be slow
    - If `--output` specified: `fs.copyFileSync(result.path, opts.output)` and update `result.path = opts.output`
    - `outputSuccess(result, globalOpts)`
    - `logSuccess('Screenshot saved to ' + result.path)`
  - Wrap in try/catch for GameKitError → outputError pattern (matching play.ts)
- Imports: `Command` from commander, `getConnection, GameKitError` from connection, `request` from bridge, `outputSuccess, outputError, logSuccess` from output, `OutputOptions` from output, `fs` from node:fs
