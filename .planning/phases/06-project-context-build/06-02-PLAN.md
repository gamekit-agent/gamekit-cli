  <action>
Create `template/Editor/GameKit/Services/BuildService.cs` as a static class in `GameKit.Services` namespace with three methods:

1. **`Build(string platform, string outputPath)`** -- Returns `object` (anonymous object with build report). Steps:
   - Call `ParseBuildTarget(platform)` to get `BuildTarget` enum value
   - Get enabled scenes: `EditorBuildSettings.scenes.Where(s => s.enabled).Select(s => s.path).ToArray()`
   - If scenes is empty, throw `new Exception("No scenes enabled in Build Settings. Add scenes via File > Build Settings.")`
   - Construct `outputPath` if not provided or empty: default to `"Builds/" + platform` under the project root. Then call `GetOutputPath(outputPath, target)` to append correct extension.
   - Ensure output directory exists: `Directory.CreateDirectory(Path.GetDirectoryName(outputPath))` (guard for null -- WebGL/Linux output path may be the directory itself, so create `outputPath` as directory if `GetDirectoryName` returns null/empty)
   - Create `BuildPlayerOptions`: `scenes`, `locationPathName = outputPath`, `target`, `options = BuildOptions.None`
   - Call `BuildPipeline.BuildPlayer(options)` -- this blocks synchronously until build completes
   - Extract result from `report.summary`: `result` (ToString), `platform` (ToString), `outputPath`, `totalSize` (ulong), `totalTime` (TotalSeconds as double), `totalErrors` (int), `totalWarnings` (int)
   - Collect errors: iterate `report.steps`, for each step iterate `step.messages` where severity is `Error`, collect `{ message = msg.content }` into a list
   - Return anonymous object with all fields above plus `errors` list

2. **`ParseBuildTarget(string platform)`** (private static) -- Switch on `platform.ToLowerInvariant()`:
   - "windows", "win", "win64", "standalonewindows64" -> `BuildTarget.StandaloneWindows64`
   - "mac", "macos", "osx", "standaloneosx" -> `BuildTarget.StandaloneOSX`
   - "linux", "linux64", "standalonelinux64" -> `BuildTarget.StandaloneLinux64`
   - "ios" -> `BuildTarget.iOS`
   - "android" -> `BuildTarget.Android`
   - "webgl" -> `BuildTarget.WebGL`
   - default: throw `new Exception($"Unknown platform: {platform}. Supported: windows, mac, linux, ios, android, webgl")`

3. **`GetOutputPath(string basePath, BuildTarget target)`** (private static) -- Append correct extension if not already present:
   - `StandaloneWindows64`: ensure ends with `.exe`
   - `StandaloneOSX`: ensure ends with `.app`
   - `Android`: ensure ends with `.apk`
   - All others (WebGL, Linux, iOS): return basePath as-is (directory-based output)

Required usings: `System`, `System.Collections.Generic`, `System.IO`, `System.Linq`, `UnityEditor`, `UnityEditor.Build.Reporting`, `UnityEngine`

Create `template/Editor/GameKit/Handlers/BuildHandler.cs` in `GameKit.Handlers` namespace:
- **`Handle(HttpListenerRequest request)`** -- reads JSON body (same pattern as SceneHandler.HandleOpen). Extracts `platform` (string, required) and `outputPath` (string, optional). If `platform` is null/empty, return `ApiResponse.Error("INVALID_REQUEST", "Missing 'platform' field")`. Call `BuildService.Build(platform, outputPath)`. Return `ApiResponse.Success(result)`. Catch exceptions: if message contains "Unknown platform", return `ApiResponse.Error("INVALID_PLATFORM", ex.Message)`. If message contains "No scenes enabled", return `ApiResponse.Error("NO_SCENES", ex.Message)`. Otherwise rethrow.

Required usings: `System`, `System.IO`, `System.Net`, `GameKit.Models`, `GameKit.Services`, `Newtonsoft.Json.Linq`

Update `template/Editor/GameKit/RequestRouter.cs` to add route (before 404 fallback):
- `POST /api/build` -> `BuildHandler.Handle(context.Request)`

- `.option('--output <path>', 'Output path (default: Builds/<platform>/)')`

Action:
- `const globalOpts = program.opts() as OutputOptions;`
- `const info = await getConnection(process.cwd());`
- Log a warning to stderr: `logWarning('Build in progress. This may take several minutes...')` (human-only)
- `const result = await request(info.port, 'POST', '/build', { platform: opts.platform, outputPath: opts.output }, 600000);` -- 10-minute timeout (600000ms)
- `outputSuccess(result, opts);`
- Human-readable output to stderr based on result:
  - If `result.result === 'Succeeded'`: `logSuccess('Build succeeded: ' + result.outputPath)`; `log('Size: ' + result.totalSize + ' bytes, Time: ' + Math.round(result.totalTime) + 's')`
  - If `result.result === 'Failed'`: `log('Build failed with ' + result.totalErrors + ' error(s)')` and log each error message. **Process should exit non-zero**: call `process.exit(1)` after outputSuccess.
  - If `result.result === 'Cancelled'`: `log('Build was cancelled')`
- Standard try/catch with GameKitError -> outputError pattern

```typescript
}
```
