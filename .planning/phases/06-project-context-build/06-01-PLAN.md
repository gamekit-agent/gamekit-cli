  <action>
Create `template/Editor/GameKit/Services/ProjectService.cs` as a static class in `GameKit.Services` namespace with four methods:

1. **`ListScripts()`** -- Returns `object` (list of anonymous objects). Uses `AssetDatabase.FindAssets("t:Script")` to find all scripts, then `AssetDatabase.GUIDToAssetPath(guid)` for each. Filter to only paths starting with `"Assets/"` and ending with `".cs"`. Return list of `{ path, name }` where name is `Path.GetFileNameWithoutExtension(path)`.

2. **`ListPrefabs()`** -- Same pattern as ListScripts but with `AssetDatabase.FindAssets("t:Prefab")`. Filter to `"Assets/"` prefix. Return list of `{ path, name }`.

3. **`GetSettings()`** -- Returns `object` containing:
   - `layers`: `InternalEditorUtility.layers` (string array)
   - `tags`: `InternalEditorUtility.tags` (string array)
   - `sortingLayers`: `SortingLayer.layers.Select(l => new { l.name, l.id, l.value }).ToArray()`
   - `physics`: anonymous object with `gravity` (as `{ x, y, z }`), `defaultContactOffset`, `bounceThreshold`, `defaultSolverIterations`, `defaultSolverVelocityIterations` from `Physics.*` static properties
   - `quality`: anonymous object with `levels` = `QualitySettings.names`, `current` = `QualitySettings.GetQualityLevel()`, `currentName` = the name at current index
   - `input`: call `GetInputAxes()` private helper

4. **`GetInputAxes()`** (private) -- Reads InputManager.asset via `SerializedObject`:
   - Load with `AssetDatabase.LoadAllAssetsAtPath("ProjectSettings/InputManager.asset")[0]`
   - Create `new SerializedObject(inputManager)`
   - Get `m_Axes` property, iterate over array elements
   - For each axis, read `m_Name`, `positiveButton`, `negativeButton`, `type` from `FindPropertyRelative`
   - Return list of `{ name, positiveButton, negativeButton, type }`
   - Wrap in try-catch: if InputManager.asset fails to load (e.g., new Input System only), return empty list

Required usings: `System`, `System.Collections.Generic`, `System.IO`, `System.Linq`, `UnityEditor`, `UnityEditorInternal`, `UnityEngine`

- `HandlePrefabs(HttpListenerRequest)` -- calls `ProjectService.ListPrefabs()`, returns `ApiResponse.Success(result)`
