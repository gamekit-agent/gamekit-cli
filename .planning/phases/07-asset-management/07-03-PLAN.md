Create `AnimatorService.cs` in `template/Editor/GameKit/Services/` as a static class in `GameKit.Services` namespace. No `[InitializeOnLoadMethod]` needed (stateless, read-only). Uses `UnityEditor.Animations` namespace for `AnimatorController`, `AnimatorState`, `AnimatorStateMachine`, `AnimatorStateTransition`, `AnimatorCondition`. Implement:

**`ListAnimator(string path)`:**
- Call `ResolveController(path)` to get the `AnimatorController`
- Iterate `controller.layers`: for each layer, iterate `layer.stateMachine.states` to collect states
- For each `ChildAnimatorState.state`: collect name, tag, speed, motion name (`.motion?.name`), and transitions
- For each `AnimatorStateTransition`: collect destinationState (check `.isExit` -> "(Exit)", else `.destinationState?.name`), hasExitTime, exitTime, duration, and conditions
- For each `AnimatorCondition`: collect parameter, mode (`.ToString()`), threshold
- Iterate `controller.parameters`: for each, collect name, type (`.ToString()` -- Float, Int, Bool, Trigger), defaultFloat, defaultInt, defaultBool
- Return: `{ name, path (AssetDatabase.GetAssetPath(controller)), layerCount, parameterCount, layers[], parameters[] }`

**`ResolveController(string path)` (private):**
- Try loading as asset path first: `AssetDatabase.LoadAssetAtPath<AnimatorController>(path)`
- If that succeeds, return it
- If null, try as `AnimatorOverrideController`: `AssetDatabase.LoadAssetAtPath<AnimatorOverrideController>(path)` -- if found, access `.runtimeAnimatorController` and cast to `AnimatorController`
- If still null, try as scene GameObject path: `SceneService.FindGameObjectByPath(path)`, get `Animator` component, access `.runtimeAnimatorController`
  - Cast to `AnimatorController` first
  - If that fails, check for `AnimatorOverrideController` and get underlying controller
- If all fail, throw: `"No AnimatorController found at: {path}. Provide an asset path (e.g., Assets/Animations/MyController.controller) or a scene GameObject path with an Animator component."`

Create `AnimatorHandler.cs` in `template/Editor/GameKit/Handlers/`:

**`HandleList(HttpListenerRequest request)`:** Read `path` query parameter from GET request. Validate non-empty (error code `MISSING_PATH`). Call `AnimatorService.ListAnimator(path)`. Error codes: `MISSING_PATH`, `NOT_FOUND`, `INTERNAL_ERROR`.

Register route in `RequestRouter.cs`:
- `GET /api/animator/list` -> `AnimatorHandler.HandleList`

Add this route in the `else if` chain before the final `else` (404) block.
