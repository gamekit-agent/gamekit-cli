Create `PrefabService.cs` in `template/Editor/GameKit/Services/` as a static class in `GameKit.Services` namespace. No `[InitializeOnLoadMethod]` needed (stateless, like SceneService). Implement:

**`CreatePrefab(string gameObjectPath, string assetPath, bool connect)`:**
- Call `GuardPlayMode()` (private helper, same pattern as AuthoringService)
- Find the scene GameObject via `SceneService.FindGameObjectByPath(gameObjectPath)` -- throw if null
- Default `assetPath` to `Assets/Prefabs/<go.name>.prefab` if null/empty
- Ensure directory exists using `AssetDatabase.CreateFolder` recursively (write a private `CreateFolderRecursive(string path)` helper that splits on `/` and creates each missing folder via `AssetDatabase.CreateFolder`)
- If `connect` is true: use `PrefabUtility.SaveAsPrefabAssetAndConnect(go, assetPath, InteractionMode.AutomatedAction, out success)`
- If `connect` is false: use `PrefabUtility.SaveAsPrefabAsset(go, assetPath, out success)`
- Throw if `!success`
- Query `PrefabUtility.GetPrefabAssetType(prefab)` to report Regular vs Variant
- Return anonymous object: `{ path, name, type (Regular/Variant/Model), isVariant }`

**`InstantiatePrefab(string prefabPath, string parentPath)`:**
- Call `GuardPlayMode()`
- Load prefab: `AssetDatabase.LoadAssetAtPath<GameObject>(prefabPath)` -- throw if null
- Instantiate: `(GameObject)PrefabUtility.InstantiatePrefab(prefab)`
- Register undo: `Undo.RegisterCreatedObjectUndo(instance, "Instantiate Prefab")`
- If parentPath provided: find parent via `SceneService.FindGameObjectByPath`, if not found call `Undo.DestroyObjectImmediate(instance)` then throw. Set parent via `Undo.SetTransformParent`.
- Return: `{ name, path (via SceneService.GetHierarchyPath), instanceId, prefabPath }`

**`GetOverrides(string gameObjectPath)`:**
- Find GameObject via `SceneService.FindGameObjectByPath` -- throw if null
- Check `PrefabUtility.IsPartOfPrefabInstance(go)` -- throw if not a prefab instance
- Get `PrefabUtility.GetPropertyModifications(go)` and filter out default overrides via `PrefabUtility.IsDefaultOverride(mod)`
- Map modifications to: `{ target (name), targetType, propertyPath, value }`
- Check `PrefabUtility.HasPrefabInstanceAnyOverrides(go, false)` for summary
- Return: `{ gameObject, path, isPrefabInstance, assetType, hasOverrides, overrides[] }`

Create `PrefabHandler.cs` in `template/Editor/GameKit/Handlers/` following the same pattern as `CreateHandler.cs`:

**`HandleCreate(HttpListenerRequest request)`:** Parse JSON body with fields `gameObjectPath` (required), `assetPath` (optional), `connect` (optional bool, default true per research recommendation). Call `PrefabService.CreatePrefab`. Error codes: `MISSING_FIELD`, `NOT_FOUND`, `PLAY_MODE`, `INTERNAL_ERROR`.

**`HandleInstantiate(HttpListenerRequest request)`:** Parse JSON body with fields `prefabPath` (required), `parent` (optional). Call `PrefabService.InstantiatePrefab`. Error codes: `MISSING_FIELD`, `NOT_FOUND`, `PARENT_NOT_FOUND`, `PLAY_MODE`.

**`HandleOverrides(HttpListenerRequest request)`:** Read `path` query parameter from GET request. Call `PrefabService.GetOverrides`. Error codes: `MISSING_PATH`, `NOT_FOUND`, `NOT_PREFAB_INSTANCE`.

Register routes in `RequestRouter.cs`:
- `POST /api/prefab/create` -> `PrefabHandler.HandleCreate`
- `POST /api/prefab/instantiate` -> `PrefabHandler.HandleInstantiate`
- `GET /api/prefab/overrides` -> `PrefabHandler.HandleOverrides`

Add these routes in the `else if` chain before the final `else` (404) block.

- `outputSuccess(result, globalOpts)` then `logSuccess` with path and type info
- Error handling: `NOT_FOUND` with hierarchy tip, `PLAY_MODE` with play stop tip
