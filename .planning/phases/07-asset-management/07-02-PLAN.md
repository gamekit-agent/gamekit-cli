Create `MaterialService.cs` in `template/Editor/GameKit/Services/` as a static class in `GameKit.Services` namespace. No `[InitializeOnLoadMethod]` needed (stateless). Implement:

**`CreateMaterial(string name, string shaderName, string outputPath)`:**
- Find shader: `Shader.Find(shaderName)` -- throw with helpful message if null (include shader name in error)
- Create material: `new Material(shader)`, set `material.name = name`
- Default `outputPath` to `Assets/Materials/<name>.mat` if null/empty
- Ensure directory exists using `CreateFolderRecursive(string path)` helper (split on `/`, check `AssetDatabase.IsValidFolder`, create via `AssetDatabase.CreateFolder`)
- Save: `AssetDatabase.CreateAsset(material, outputPath)` then `AssetDatabase.SaveAssets()`
- Return: `{ path, name, shader (shaderName) }`

**`SetProperty(string materialPath, string property, JToken value)`:**
- Load material: `AssetDatabase.LoadAssetAtPath<Material>(materialPath)` -- throw if null
- Validate property exists: `material.shader.FindPropertyIndex(property)` -- if < 0, throw error listing available properties via `ListShaderProperties(shader)` helper
- Get property type: `material.shader.GetPropertyType(propIndex)`
- Dispatch by type using a `SetPropertyByType(material, property, ShaderPropertyType propType, JToken value)` switch:
  - `ShaderPropertyType.Color`: `material.SetColor(property, new Color(value["r"] ?? 0, value["g"] ?? 0, value["b"] ?? 0, value["a"] ?? 1))`
  - `ShaderPropertyType.Float` and `ShaderPropertyType.Range`: `material.SetFloat(property, value.Value<float>())`
  - `ShaderPropertyType.Vector`: `material.SetVector(property, new Vector4(value["x"] ?? 0, value["y"] ?? 0, value["z"] ?? 0, value["w"] ?? 0))`
  - `ShaderPropertyType.Int`: `material.SetInteger(property, value.Value<int>())`
  - `ShaderPropertyType.Texture`: load via `AssetDatabase.LoadAssetAtPath<Texture>(texPath)` if string, set null if null
  - Default: throw unsupported type
- Persist: `EditorUtility.SetDirty(material)` then `AssetDatabase.SaveAssets()`
- Read back via `ReadPropertyByType(material, property, propType)` helper (mirrors the set switch but uses Get* methods)
- Return: `{ path, property, value (read back), type (propType.ToString()) }`

**`AssignMaterial(string materialPath, string gameObjectPath)`:**
- Call `GuardPlayMode()` (private helper, same as AuthoringService)
- Load material: `AssetDatabase.LoadAssetAtPath<Material>(materialPath)` -- throw if null
- Find GameObject: `SceneService.FindGameObjectByPath(gameObjectPath)` -- throw if null
- Get Renderer: `go.GetComponent<Renderer>()` -- throw if null ("No Renderer component on: ...")
- Record undo: `Undo.RecordObject(renderer, "Assign Material")`
- Assign: `renderer.sharedMaterial = material` (NOT `.material` -- avoid runtime copy leak)
- Return: `{ gameObject, material (name), materialPath, gameObjectPath }`

**Helper: `ListShaderProperties(Shader shader)`** -- iterate `shader.GetPropertyCount()`, collect `{ name, type }` pairs for error messages.

**Helper: `ReadPropertyByType(Material material, string property, ShaderPropertyType type)`** -- switch returning Color as `{r,g,b,a}`, Float/Range as float, Vector as `{x,y,z,w}`, Int as int, Texture as asset path string.

**Helper: `CreateFolderRecursive(string path)`** -- split path on `/`, walk from root creating each missing folder via `AssetDatabase.CreateFolder(parentPath, folderName)`.

Create `MaterialHandler.cs` in `template/Editor/GameKit/Handlers/`:

**`HandleCreate(HttpListenerRequest request)`:** Parse JSON body: `name` (required), `shader` (optional, default `"Standard"`), `outputPath` (optional). Call `MaterialService.CreateMaterial`. Error codes: `MISSING_FIELD`, `SHADER_NOT_FOUND`, `INTERNAL_ERROR`.

**`HandleSet(HttpListenerRequest request)`:** Parse JSON body: `materialPath` (required), `property` (required), `value` (required, any JToken). Call `MaterialService.SetProperty`. Error codes: `MISSING_FIELD`, `NOT_FOUND`, `PROPERTY_NOT_FOUND`, `INVALID_VALUE`.

**`HandleAssign(HttpListenerRequest request)`:** Parse JSON body: `materialPath` (required), `gameObjectPath` (required). Call `MaterialService.AssignMaterial`. Error codes: `MISSING_FIELD`, `NOT_FOUND`, `NO_RENDERER`, `PLAY_MODE`.

Register routes in `RequestRouter.cs`:
- `POST /api/material/create` -> `MaterialHandler.HandleCreate`
- `POST /api/material/set` -> `MaterialHandler.HandleSet`
- `POST /api/material/assign` -> `MaterialHandler.HandleAssign`

Add these routes in the `else if` chain before the final `else` (404) block. **Note:** Plan 07-01 also modifies RequestRouter.cs -- if executing sequentially, just append after the prefab routes. If executing in parallel, place material routes in a distinct block. Either way, the routes are independent and do not conflict.

**`material create <name>`:**
- Options: `--shader <shaderName>` (default `"Standard"`), `--output <assetPath>` (output path)
- POST `/material/create` with body: `{ name, shader: opts.shader ?? 'Standard', outputPath: opts.output }`
- `outputSuccess(result, globalOpts)` then `logSuccess('Created: <path> (shader: <shader>)')`
- Error handling: `SHADER_NOT_FOUND` with tip about common shader names (Standard, Universal Render Pipeline/Lit, HDRP/Lit)

**`material set <materialPath> <property> <value>`:**
- Reuse the `parseValue` pattern from `set.ts` (copy the function or make it a shared utility). The value parser handles comma-separated RGBA/vectors, JSON objects, booleans, numbers, and strings.
- For material properties, extend: if 4 comma-separated numbers, map to `{r, g, b, a}` instead of `{x, y, z, w}` (material colors use r/g/b/a keys). Detect this by adding a `--color` flag OR by always sending both key sets and letting the Unity side pick the right one. **Simplest approach:** send comma-separated values as `{r, g, b, a}` for 4-component and `{x, y, z, w}` for others. Actually, even simpler: the Unity side reads by ShaderPropertyType, so for Color it reads `value["r"]`, for Vector it reads `value["x"]`. Send `{x,y,z,w}` always from CLI (matching existing set.ts pattern). In MaterialService.SetPropertyByType for Color, read `value["r"]` first, falling back to `value["x"]` if r is absent. This way CLI doesn't need to know the property type.
- POST `/material/set` with body: `{ materialPath, property, value: parsedValue }`
- `outputSuccess(result, globalOpts)` then `logSuccess('Set <property> on <path>')`
- Error handling: `NOT_FOUND`, `PROPERTY_NOT_FOUND` (with available properties from error message)

**`material assign <materialPath> <gameObjectPath>`:**
- POST `/material/assign` with body: `{ materialPath, gameObjectPath }`
- `outputSuccess(result, globalOpts)` then `logSuccess('Assigned <material> to <gameObject>')`
- Error handling: `NOT_FOUND`, `NO_RENDERER` with tip about adding a MeshRenderer, `PLAY_MODE`
