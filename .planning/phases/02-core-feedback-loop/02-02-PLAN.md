Create `template/Editor/GameKit/Models/LogEntry.cs`:
- Class in `GameKit.Models` namespace with [JsonProperty] attributes for lowercase field names
- Fields: message (string), stackTrace (string, nullable), severity (string -- "error", "warning", or "info"), mode (string -- "edit" or "play"), timestamp (string, ISO 8601), sequence (long -- monotonic counter for SSE cursor)

Create `template/Editor/GameKit/Services/LogService.cs`:
- Static class in `GameKit.Services` namespace
- Private static ring buffer: `LogEntry[] _buffer = new LogEntry[2000]`
- Private static `int _writeIndex`, `int _totalCount`, `long _sequence` (use `System.Threading.Interlocked.Increment` for sequence)
- Private static `List<Action<LogEntry>> _listeners` for SSE subscribers
- [InitializeOnLoadMethod] Init() that subscribes to:
  - `Application.logMessageReceived += OnLogReceived` -- captures message, stackTrace, LogType
  - Note: This re-subscribes on domain reload, which is correct behavior
- `OnLogReceived(string message, string stackTrace, LogType type)`:
  - Create LogEntry with: message, stackTrace (only for LogType.Exception, LogType.Error, LogType.Assert -- null for others), severity from MapSeverity(type), mode = `EditorApplication.isPlaying ? "play" : "edit"`, timestamp = `DateTime.UtcNow.ToString("o")`, sequence from Interlocked.Increment
  - Store in ring buffer at `_writeIndex % _buffer.Length`, increment _writeIndex and _totalCount
  - Notify all listeners (iterate a copy: `_listeners.ToArray()`) with the new entry
- `MapSeverity(LogType type)` returning: "error" for Error/Exception/Assert, "warning" for Warning, "info" for Log
- `GetEntries(string severityFilter = null)` returning `List<LogEntry>`:
  - Collect non-null entries from the ring buffer (from oldest to newest)
  - If severityFilter is not null, filter entries where entry.severity == severityFilter
  - Return the list, along with metadata: totalCount, droppedCount (totalCount - actual entries in buffer)
- Return type should be a result object: `(List<LogEntry> entries, int totalCount, int droppedCount)`
- `AddListener(Action<LogEntry> listener)` and `RemoveListener(Action<LogEntry> listener)`
- `Clear()` method that resets buffer, _writeIndex, _totalCount (but NOT _sequence -- sequence is monotonic)

Create `template/Editor/GameKit/Handlers/ConsoleHandler.cs`:
- Static class in `GameKit.Handlers` namespace
- `Handle(HttpListenerRequest request)` returning ApiResponse (for GET /api/console):
  - Parse query parameter `severity` from request.QueryString["severity"] (nullable)
  - Call `LogService.GetEntries(severity)` to get filtered entries
  - Return `ApiResponse.Success(new { entries, totalCount, droppedCount })`
- `HandleStream(HttpListenerContext context)` returning void (for GET /api/console/stream):
  - This method handles the SSE streaming -- it does NOT return an ApiResponse because it holds the connection open
  - Set `context.Response.ContentType = "text/event-stream"`
  - Set `context.Response.SendChunked = true`
  - Add headers: `Cache-Control: no-cache`, `Connection: keep-alive`
  - Create StreamWriter on context.Response.OutputStream with UTF8 encoding and AutoFlush = true
  - Create a listener lambda `Action<LogEntry>` that serializes the entry to JSON and writes `data: {json}\n\n` format. Wrap in try/catch -- on exception, set a `disconnected` flag
  - Call `LogService.AddListener(listener)`
  - Send an initial SSE comment as heartbeat: write `": connected\n\n"` to confirm the stream is alive
  - Keep connection open by blocking: use a `ManualResetEventSlim` that is only set when `disconnected` becomes true. Wait with a 15-second timeout for periodic heartbeat sends: `": heartbeat\n\n"`. When disconnected, remove listener and close response.
  - IMPORTANT: This method runs on the HttpListener thread (NOT main thread) because SSE must not block the main thread. The RequestRouter must call HandleStream DIRECTLY from the async context, NOT via MainThreadDispatcher.

- Add a new public static method `HandleStreamRequest(HttpListenerContext context)` that checks if the path is `/api/console/stream` and if so, calls `ConsoleHandler.HandleStream(context)` directly (no WriteResponse).
- OR: modify HandleRequest to detect GET /api/console/stream and call ConsoleHandler.HandleStream(context) directly, then return without calling WriteResponse. The simplest approach:

Use Option A: Modify `GameKitServer.OnRequestReceived` to check `context.Request.Url.AbsolutePath`. If it equals `/api/console/stream`, call `RequestRouter.HandleRequest(context)` directly. Create `src/commands/console.ts`:
- Import `getConnection` from `../utils/connection.js`
- Import `request` from `../utils/bridge.js`
- Import `GameKitError` from `../utils/connection.js`
- Import `outputSuccess`, `outputError`, `log` from `../utils/output.js`

Define interfaces:
- `LogEntry`: { message: string, stackTrace: string | null, severity: string, mode: string, timestamp: string, sequence: number }
- `ConsoleResult`: { entries: LogEntry[], totalCount: number, droppedCount: number }
- `ConsoleOptions`: { json?: boolean, errors?: boolean, warnings?: boolean, info?: boolean, follow?: boolean }

Export async function `consoleCommand(options: ConsoleOptions)`:
- Call `getConnection(process.cwd())`
- If `options.follow` is true, call `streamLogs(info.port, options)` and return
- Build severity filter: if options.errors -> "error", if options.warnings -> "warning", if options.info -> "info", else null
- Build query string: severity ? `?severity=${severity}` : ""
- Call `request<ConsoleResult>(info.port, 'GET', '/console' + query)`
- Call `outputSuccess(result, options)` for JSON output
- Use `log()` for human-readable: if droppedCount > 0, warn about dropped logs. Then format each entry as:
  `[{timestamp}] [{mode}] {severity}: {message}` (and stackTrace on next line if present)

Implement `streamLogs(port: number, options: ConsoleOptions)`:
- Construct URL: `http://localhost:${port}/api/console/stream`
- Use raw `fetch(url)` (NOT the bridge request<T>, since SSE is not a standard API response)
- Get reader: `const reader = res.body!.getReader()`
- Set up TextDecoder and buffer for SSE parsing
- Register SIGINT handler: `process.on('SIGINT', () => { reader.cancel(); process.exit(0); })`
- Read loop: `while (true) { const { done, value } = await reader.read(); if (done) break; ... }`
- Parse SSE: split buffer on `\n\n`, for each complete event starting with `data: `, parse JSON as LogEntry
- Apply client-side severity filter: if options.errors/warnings/info is set, skip entries that don't match
- Output each matching entry: write `JSON.stringify(entry) + '\n'` to stdout (one JSON object per line, NDJSON format)
- Also write human-readable format to stderr via `log()` if TTY
- On connection drop (reader.read() returns done=true), attempt reconnect: wait 1 second, retry fetch. Max 5 retries with exponential backoff (1s, 2s, 4s, 8s, 16s). Log reconnection attempts to stderr. On final failure, call `outputError('STREAM_DISCONNECTED', 'Lost connection to Unity log stream')`.

Update `src/index.ts`:
- Import `consoleCommand` from `./commands/console.js`
- Add command registration (note: cannot use `console` as a method name since it shadows global):

  ```
  program

      } catch (error) {

          outputError(error.code, error.message);
        }
        throw error;
      }
    });
  ```
