  <action>
Create `template/Editor/GameKit/Handlers/PlayHandler.cs`:
- Static class in `GameKit.Handlers` namespace
- Three static methods, each taking `HttpListenerRequest request` and returning `ApiResponse`:

`HandleStart(HttpListenerRequest request)`:
- If `EditorApplication.isCompiling`, return `ApiResponse.Error("COMPILING", "Cannot enter play mode while compiling")`
- If `EditorApplication.isPlaying`, return `ApiResponse.Success(new { status = "already_playing" })`
- Call `EditorApplication.EnterPlaymode()`
- Return `ApiResponse.Success(new { status = "entering_play_mode" })`

`HandleStop(HttpListenerRequest request)`:
- If `!EditorApplication.isPlaying`, return `ApiResponse.Success(new { status = "already_stopped" })`
- Call `EditorApplication.ExitPlaymode()`
- Return `ApiResponse.Success(new { status = "exiting_play_mode" })`

`HandleStatus(HttpListenerRequest request)`:
- Determine state string:
  - If `EditorApplication.isPlaying && EditorApplication.isPaused` -> "paused"
  - If `EditorApplication.isPlaying` -> "playing"
  - Else -> "stopped"
- Return `ApiResponse.Success(new { state })`

Update `template/Editor/GameKit/RequestRouter.cs`:
- Add three routes inside the try/catch block (after the existing /api/console route):
  - `method == "POST" && path == "/api/play/start"` -> `PlayHandler.HandleStart(context.Request)`
  - `method == "POST" && path == "/api/play/stop"` -> `PlayHandler.HandleStop(context.Request)`
  - `method == "GET" && path == "/api/play/status"` -> `PlayHandler.HandleStatus(context.Request)`

Create `src/commands/play.ts`:
- Import `Command` from `commander`
- Import `getConnection` from `../utils/connection.js`
- Import `request` from `../utils/bridge.js`
- Import `GameKitError` from `../utils/connection.js`
- Import `outputSuccess`, `outputError`, `logSuccess`, `log` from `../utils/output.js`
- Import `OutputOptions` from `../utils/output.js`

Define interfaces:
- `PlayActionResult`: { status: string } -- for start/stop responses
- `PlayStatusResult`: { state: string } -- for status response

Export function `registerPlayCommand(program: Command)`:
- Create parent command: `const play = program.command('play').description('Control Unity play mode')`
- Add subcommand `start`:
  ```
  play.command('start')
    .description('Enter play mode')
    .action(async () => {
      try {
        const opts = program.opts() as OutputOptions;
        const info = await getConnection(process.cwd());
        const result = await request<PlayActionResult>(info.port, 'POST', '/play/start');
        outputSuccess(result, opts);
        if (result.status === 'entering_play_mode') {
          logSuccess('Entering play mode');
        } else if (result.status === 'already_playing') {
          log('Already in play mode');
        }
      } catch (error) {
        if (error instanceof GameKitError) {
          outputError(error.code, error.message);
        }
        throw error;
      }
    });
  ```
- Add subcommand `stop`:
  ```
  play.command('stop')
    .description('Exit play mode')
    .action(async () => {
      try {
        const opts = program.opts() as OutputOptions;
        const info = await getConnection(process.cwd());
        const result = await request<PlayActionResult>(info.port, 'POST', '/play/stop');
        outputSuccess(result, opts);
        if (result.status === 'exiting_play_mode') {
          logSuccess('Exiting play mode');
        } else if (result.status === 'already_stopped') {
          log('Already stopped');
        }
      } catch (error) {
        if (error instanceof GameKitError) {
          outputError(error.code, error.message);
        }
        throw error;
      }
    });
  ```
- Add subcommand `status`:
  ```
  play.command('status')
    .description('Check play mode state')
    .action(async () => {
      try {
        const opts = program.opts() as OutputOptions;
        const info = await getConnection(process.cwd());
        const result = await request<PlayStatusResult>(info.port, 'GET', '/play/status');
        outputSuccess(result, opts);
        log(`Play mode: ${result.state}`);
      } catch (error) {
        if (error instanceof GameKitError) {
          outputError(error.code, error.message);
        }
        throw error;
      }
    });
  ```
