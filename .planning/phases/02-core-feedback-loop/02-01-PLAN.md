Create `src/commands/refresh.ts`:
- Import `getConnection` from `../utils/connection.js`
- Import `request` from `../utils/bridge.js`
- Import `outputSuccess`, `outputError`, `log`, `logSuccess` from `../utils/output.js`
- Import `GameKitError` from `../utils/connection.js`
- Define `RefreshResult` interface: `{ status: string; errors: Array<{ file: string; line: number; column: number; message: string; severity: 'error' | 'warning' }> }`
- Export async function `refresh(options: { json?: boolean })`:
  1. Call `getConnection(process.cwd())` to discover Unity
  2. Call `request<RefreshResult>(info.port, 'POST', '/refresh', null, 60000)` -- 60s timeout for large projects
  3. If `result.status === 'compiling'`, poll: loop calling `request<RefreshResult>(info.port, 'POST', '/refresh', null, 60000)` every 1000ms (with `await new Promise(r => setTimeout(r, 1000))`) until status is not 'compiling', max 30 retries. This handles the async compilation case.
  4. Count errors and warnings from result.errors
  5. If there are errors with severity 'error':
     - Call `outputSuccess({ success: false, errors: result.errors, errorCount, warningCount }, options)` to write JSON to stdout
     - Use `log()` to write human-readable error listing to stderr: each error as `  {file}:{line}:{column} {severity}: {message}`
     - Call `process.exit(1)` for COMP-03 (non-zero exit on errors)
  6. If no errors:
     - Call `outputSuccess({ success: true, errors: result.errors, errorCount: 0, warningCount }, options)` (warnings may exist)
     - Call `logSuccess('Compilation successful')` (or `logSuccess('Compilation successful (N warnings)')` if warnings exist)

Update `src/index.ts`:
- Import `refresh` from `./commands/refresh.js`
- Add command registration:

  ```
  program
    .command('refresh')
    .description('Trigger Unity recompilation and return results')
    .action(async () => {
      try {
        await refresh(program.opts());
      } catch (error) {
        if (error instanceof GameKitError) {
          outputError(error.code, error.message);
        }
        throw error;
      }
    });
  ```
